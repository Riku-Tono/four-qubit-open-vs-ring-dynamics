# 継ぎ目をまたぐ2組の短時間展開

2026年11月9日。前回と同じ \(\Omega=1\)、\(J=0.7\)、\(\epsilon=0\) で、弱結合枝 \(\lambda=0.5\) と開放鎖 \(\lambda=0\) を比べた。初期状態は左端だけを励起した \(\lvert1000\rangle\)、\(\lvert100000\rangle\)。対象は \(02\to04\) と \(13\to15\) の連結相関 \(C_{ij}^{aa}(t)=\langle\sigma_i^a\sigma_j^a\rangle-\langle\sigma_i^a\rangle\langle\sigma_j^a\rangle\)。

## 最初にゼロでない項

\(M=40H\) として整数ベクトル \(v_k=M^k\lvert A\rangle\) を20次まで計算した。各期待値の \(t^n\) 係数は

\[
[t^n]\langle O\rangle_t=\frac{i^n}{40^n n!}\sum_{k=0}^{n}(-1)^k\binom{n}{k}\langle v_{n-k}|O|v_k\rangle.
\]

一体期待値の積を級数として引き、表の次数より低い係数がすべてゼロであることを確認した。実ハミルトニアンと実初期状態では、同軸の二体期待値は \(t\) の偶関数になる。一体期待値は \(X,Z\) が偶関数、\(Y\) が奇関数なので、同軸の連結相関も偶関数である。独立したパウリ演算子の入れ子交換子でも24条件の先頭項を照合した。

## 経路が変わると何が変わるか

開放鎖では比較する各ペアを結ぶ経路が1本で、途中のどの結合を外しても2サイトは別々の連結成分になる。初期状態が積状態なので、その場合の連結相関は恒等的にゼロになる。したがって非ゼロの級数項には経路上の結合がすべて関わる。今回、開放鎖の経路が2辺から4辺に伸びると、\(XX,YY,ZZ\) の最初の次数はいずれも8上がった。04の開放鎖では \(XX\) の先頭係数の符号も負から正に変わった。弱結合枝では継ぎ目を通る2辺の経路があり、次数は \((6,8,10)\) のままだった。

4量子ビットの弱結合枝には、両ペアとも2辺の経路が2本ある。\(XX\) の \(t^6\) 係数に限っては、中央結合 \(12\) を切って継ぎ目経由だけにすると \(\mp49/1800\)、継ぎ目を切って開放鎖経由だけにすると \(\mp49/900\) で、足すと両経路があるときの \(\mp49/600\) になる。上側の符号が02、下側が13。この確認では元の条件の計算とは別に、中央結合を切った4量子ビット系を使った。

したがって枝間差 \(D=C_{0.5}-C_0\) の **XX の先頭係数は4→6で一致する**。\(02\to04\) が \(-49/1800\)、\(13\to15\) が \(+49/1800\) で、いずれも \(t^6\) の係数。4量子ビットでは引き算で開放鎖経由の寄与が消え、6量子ビットでは開放鎖のXXが \(t^{14}\) で始まるためである。YYとZZの枝間差はどちらの対応でも6量子ビット側の先頭係数の絶対値が小さい。\(T=3.688\) までの XX の二乗積分差を説明するには、先頭の \(t^6\) より高い項も関わる。

## 有限時刻の数値波形による確認

級数係数を求める計算とは別に、指数演算子のチェビシェフ展開で有限時刻の状態を求めた。指数演算子を80桁で計算し、\(t=0.4,0.2,0.1,0.05,0.025,0.0125\) で連結相関を直接評価した。96桁に上げて多項式次数も64から80に増やしたとき、全波形の最大相対変化は \(2.4\times10^{-35}\)。前回の倍精度波形との共通時刻での最大絶対差は \(1.0\times10^{-15}\) 未満だった。 [Tal-Ezer と Kosloff のチェビシェフ伝播法](https://cris.huji.ac.il/en/publications/an-accurate-and-efficient-scheme-for-propagating-the-time-depende/)

| \(t\) | 24条件における \(\lvert C(t)/(a t^p)-1\rvert\) の最大値 |
|---:|---:|
| 0.1 | \(1.0744\times10^{-2}\) |
| 0.05 | \(2.6965\times10^{-3}\) |
| 0.025 | \(6.7478\times10^{-4}\) |
| 0.0125 | \(1.6874\times10^{-4}\) |

時間半減で誤差はほぼ4分の1になり、\(C(t)/(a t^p)=1+O(t^2)\) と整合する。\(t=0.025\) の開放6量子ビット・04のZZは \(-8.74\times10^{-40}\) なので、高精度で二体期待値と一体期待値の積を引いた。最小の2時刻から求めた有効次数 \(\log_2|C(0.025)/C(0.0125)|\) は、24条件すべてで厳密な次数から \(7.4\times10^{-4}\) 以内だった。
