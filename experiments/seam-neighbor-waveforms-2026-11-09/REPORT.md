# 継ぎ目をまたぐ2組の相関波形と二乗積分の分解

2026年11月9日。前回と同じ \(\Omega=1\)、\(J=0.7\)、\(\epsilon=0\)、\(T=3.688\) を使用した。左端だけを励起した初期状態 \(\lvert1000\rangle\)、\(\lvert100000\rangle\) から、弱結合枝 \(\lambda=0.5\) と開放鎖 \(\lambda=0\) をそれぞれ発展させた。対象は端からの位置をそろえた \(02\to04\) と \(13\to15\) の2組。

## 枝ごとの二乗項と交差項

同一ペア・同一チャネルの連結相関を、弱結合枝で \(C_L(t)\)、開放鎖で \(C_0(t)\) とする。以下の積分はすべて \([0,3.688]\) で、刻み \(0.001\) の台形則を使った。

\[
U=\int C_L^2\,dt,\qquad V=\int C_0^2\,dt,\qquad W=-2\int C_L C_0\,dt,\qquad
I=\int(C_L-C_0)^2\,dt=U+V+W.
\]

\(W<0\) は時間積分で同符号の重なりが優勢で、二乗差を縮める。\(W>0\) は反対符号の重なりが優勢で、二乗差を広げる。波形の大きさを除いた重なりの指標として \(\rho=-W/(2\sqrt{UV})\) も保存した。

## 波形で見える違い

- **02→04 の XX。** 4量子ビットでは両枝の大きな振れが負側にあり、弱結合枝の負のピークは \(-0.537\)（\(t=2.872\)）、開放鎖は \(-0.337\)（\(t=2.537\)）。6量子ビットでは弱結合枝の負のピークが \(-0.0945\)（\(t=2.093\)）まで小さくなり、開放鎖は終点で \(+0.1370\) まで正側に伸びる。\(\rho\) は \(+0.992\to-0.140\)、\(W\) は \(-0.54018\to+0.00244\)。枝の二乗項の減少が大きく、交差項が差を広げる向きに変わっても \(I\) は減った。
- **02→04 の YY・ZZ。** 弱結合枝の二乗項は YY で約99%、ZZ で約98%減った。開放鎖の二乗項も小さくなり、\(I\) の減少は YY で \(0.033487\)、ZZ で \(0.020113\)。6量子ビットの04では残った \(I\) の約93%が XX。
- **13→15 の XX。** 両サイズとも積分した波形の重なりは同符号が優勢で、\(\rho=+0.997\to+0.845\)。枝の二乗項が大きく減る一方、負の交差項の絶対値も減り、\(I\) の純減は \(0.013917\) だった。
- **13→15 の YY・ZZ。** 2チャネルでこの対応の減少の約85%を占めた。YY では4量子ビットの終点で弱結合枝が \(+0.174\)、開放鎖が \(-0.154\) と逆符号になり、\(W=+0.007900\)。6量子ビットの開放鎖は全区間で絶対値 \(0.002520\) 以下になり、\(W=-0.000237\) へ変わった。YY では交差項の変化も純減を後押しする。ZZ では両枝の二乗項の減少が主で、負の交差項の絶対値が小さくなる変化が一部を相殺した。

## 数値照合と再現

直接積分した \(I\) と \(U+V+W\) の差は最大 \(9.6\times10^{-16}\)。前回のペア別・チャネル別の \(I\) と最大 \(1.4\times10^{-16}\) の差で一致した。積分刻みを \(0.0005\) に半減したときの各項の最大変化は \(2.9\times10^{-8}\) 未満。独立した疎行列のテイラー時間発展でも各項を照合した。

NumPy 2.0以上の環境で `python -B run.py` を実行する。前回までの実験フォルダ `endpoint-field-six-qubit-2026-11-09` と `seam-pair-time-window-2026-11-09` を参照する。`waveforms.csv` に刻み \(0.001\) の全24波形、`results.json` に積分値・刻み半減の結果・表示用に間引いた波形を収録した。
