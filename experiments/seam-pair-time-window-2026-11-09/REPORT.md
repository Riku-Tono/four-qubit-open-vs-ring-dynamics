# 全ペア積分の4→6量子ビット差と観測時間

2026年11月9日。前回と同じ \(\Omega=1\)、\(J=0.7\)、\(\lambda=0.5\)（開放鎖の参照は \(\lambda=0\)）、\(\epsilon=0\) で計算した。初期状態Aは4量子ビットで \(\lvert1000\rangle\)、6量子ビットで \(\lvert100000\rangle\)。各ペアの積分は

\[
I_{ij}(T)=\int_0^T\sum_{a=x,y,z}\left[C_{ij}^{aa}(t,0.5)-C_{ij}^{aa}(t,0)\right]^2\,dt,
\qquad S(T)=\sum_{i<j}I_{ij}(T).
\]

\(I_{ij}\) は全体で規格化する前の寄与である。前回と同じ固有値による時間発展を \(t=4.688\) まで計算し、台形則の累積和から各 \(T\) の値を得た。初期状態Bではペア値がAの左右反射になり、\(S\) と左右の対応ペア2組の合計は一致する。

## \(T=3.688\) でどのペアが減ったか

左右それぞれ端から2サイトずつをそろえ、4量子ビットのサイト \(0,1,2,3\) を6量子ビットの \(0,1,4,5\) に対応させた。6量子ビットの中央サイト \(2,3\) のいずれかを含む9組は追加分として別に合計した。\(12\to14\) は端からの位置でそろえた対応で、ペア間の距離は異なる。

\(02\to04\) と \(13\to15\) の2組は、どちらのサイズでも継ぎ目を経由する2辺の経路を持つ。この2組の合計は \(0.232251\to0.047682\) と下がり、差 \(0.184569\) は全体の純減の **89.20%** に当たる。2組の減少をチャネル別に分けると \(XX\) が \(0.049824\)、\(YY\) が \(0.077706\)、\(ZZ\) が \(0.057039\) で、3チャネルとも減少に寄与した。

6量子ビットの追加9組の内訳は、\(02\) が \(0.004417\)、\(03\) が \(0.003388\)、\(12\) が \(0.007801\)、\(13\) が \(0.005525\)、\(23\) が \(0.000268\)、\(24\) が \(0.002451\)、\(25\) が \(0.003158\)、\(34\) が \(0.000737\)、\(35\) が \(0.016250\)。これらは \(S_6\) に加わり、対応6組の減少を一部相殺した。

ペアの一対一対応を使わず、弱リンクを含む環で最短距離が2の全ペアを集計しても、合計は \(0.232251\to0.076324\) と下がり、純減の **75.36%** を占めた。環で距離2の組数は4量子ビットで2組、6量子ビットで6組。対応する2組は継ぎ目を経由する2辺の経路を保つ一方、開放鎖側の経路は2辺から4辺に延びる。ここで求めたのはペアごとの減少の内訳であり、経路長の変化が各相関の差をどれだけ生むかは別の問いになる。

## 数値照合と再現

基準 \(T=3.688\) の全ペア積分と継ぎ目積分は、前回の保存値と最大 \(2.8\times10^{-16}\) の差で一致した。積分刻みを \(0.001\) から \(0.0005\) に半減すると、全時刻での最大変化は個別ペアで \(3.0\times10^{-8}\)、\(S\) で \(4.7\times10^{-8}\) だった。独立した疎行列のテイラー時間発展でも基準のペア積分と \(S\) を照合した。
