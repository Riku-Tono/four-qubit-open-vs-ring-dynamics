# 切替なし4bit直列対4bit円環：実行結果

## 実行条件

- N = 4
- Omega = 1.0
- J = 0.7
- 初期状態 = `|0000>`
- 時間範囲 = `0 <= t <= 3.688`
- 直列 = `(0,1), (1,2), (2,3)`
- 円環 = 直列に `(3,0)` を追加
- 両方とも `t=0` から固定Hamiltonianで発展
- 主刻み `dt=0.002`、監査刻み `dt=0.001`

途中の結合切替やquenchはない。

## 主結果

| 量 | 値 |
|---|---:|
| `t=3.688` の枝間状態距離 | `0.544161993982` |
| `t=3.688` のfidelity | `0.725808344260` |
| 観測時間内の最大状態距離 | `0.546934944036` |
| 最大距離の時刻 | `3.462` |

状態距離はglobal phase不変の `sqrt(2 - 2 |<psi_open|psi_closed>|)` を使用した。

## 数値監査

- Rust tests: `8 passed / 0 failed`
- `cargo fmt --all -- --check`: PASS
- norm error: 両枝とも全保存時刻でテスト閾値 `1e-12` 未満
- `dt=0.002` 対 `dt=0.001` の最大状態差:
  - open: `4.8514666e-7`
  - closed: `7.2695678e-7`
- exact diagonalization対`dt=0.002`の枝間距離残差:
  - 全時刻最大 `4.5928342e-8`
  - `t=3.688` で `2.0181747e-8`

## 局所応答追加解析

サイト別応答を R_i=<n_i> と新たに定義し、fixed版とquench版を同じ量で解析した。fixed closedは全時刻で4サイト一様、fixed openは初期縮退後に端点ペア0|3が最大で、その後の最大位置移動はなかった。詳細は LOCAL_RESPONSE_ANALYSIS_REPORT.md を参照。

## 位置づけ

この結果は、N=4有限系で固定open境界と固定closed境界を同じ初期状態から直接比較した記録である。既存の`t_switch=1.688`局所quench実験とは別であり、一般的な境界機構、輸送則、相転移、熱力学極限、N=7 Lindblad逆流との同一機構を主張しない。
